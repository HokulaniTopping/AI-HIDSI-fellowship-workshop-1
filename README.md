# Sketch to App: Building with Generative AI

A beginner-friendly, hands-on workshop for the AI HIDSI Fellowship. Attendees sketch an app on paper or an iPad, then use AI to build a working version of it. Along the way they learn how generative AI works, how to write better prompts, and how to check AI's work.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/HokulaniTopping/AI-HIDSI-fellowship-workshop-1/blob/main/Sketch_to_App_Workshop.ipynb)

## What you'll do

| Part | Activity |
| --- | --- |
| 0 | Set up a free Gemini API key |
| 1 | Intro to generative AI |
| 2 | Brainstorm an app idea with AI |
| 3 | Sketch your app, label the buttons, and have AI build it |
| 4 | Make it better with clearer prompts |
| 5 | Write a Markdown plan file and have AI build from it |
| 6 | Compare ChatGPT, Gemini, and Claude and check their work |
| 7 | Download your app and publish it with GitHub Pages |
| 8 | Wrap-up: habits for using AI well |

## Before you come

- **No coding experience needed.**
- Bring a laptop, plus paper and a pen (or an iPad) for sketching.
- Have a Google account so you can use Colab and get a free Gemini API key.
- Optional: free accounts on [ChatGPT](https://chatgpt.com/), [Gemini](https://gemini.google.com/), [Claude](https://claude.ai/), and [GitHub](https://github.com/).
